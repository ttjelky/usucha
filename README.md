# USUCHA — Matcha Bar & Kitchen

A concept website for a fictional matcha bar, built as a portfolio piece.

**Live:** https://ttjelky.github.io/usucha/

## Highlights

- Editorial layout: oversized grotesk headings paired with italic serif accents
- Scroll-driven "exploded drink" anatomy — six CSS-only layers that separate as you scroll
- Filterable signature drinks grid and a tabbed full menu
- Working order drawer (add / remove / quantities, persisted in `localStorage`)
- Sticky ritual timeline with progress bar and active-step highlighting
- Live open/closed status, table booking and newsletter forms with validation
- Parallax hero, pointer tilt, marquee, count-up and reveal animations
- Responsive from 360px to wide desktop; respects `prefers-reduced-motion`
- Zero dependencies — plain HTML, CSS and JavaScript, no build step

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
